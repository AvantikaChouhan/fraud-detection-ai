# Real-Time Fraud Detection & AI Analytics Platform

## Project Overview

An end-to-end data engineering and AI platform for detecting
fraudulent transactions using real-time streaming, scalable data
processing, Delta Lake, machine learning and GenAI.

## Technology Stack

- Python
- Apache Kafka
- PySpark
- Databricks
- Delta Lake
- SQL
- Machine Learning
- Azure OpenAI
- Streamlit / Power BI

## Architecture

Kaggle Dataset
→ Kafka
→ Spark Structured Streaming
→ Bronze
→ Silver
→ Gold
→ Fraud Detection
→ AI Explanation

## Dataset

Credit Card Fraud Detection dataset from Kaggle.
